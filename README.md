# Kairo AI - Personal Voice & Phone Control Agent

**Kairo** tumhara personal AI assistant hai jo tumhari awaaz sunta hai, Urdu/English mein baat karta hai aur poora Android phone control karta hai.

## Kairo Ko Kaise Use Karein?
1. App mein **Accessibility Permission ON** karein.
2. Apni **Gemini API Key** daalein aur **"Kairo Listening ON Karein"** par tap karein.
3. Ab mobile side par rakh dein ya koi bhi app chalayein — jab bhi tum kahoge:
   - *"Hey Kairo"* -> Kairo jawab dega: **"Ji boss, Kairo hazir hai! Hukam karein."**
   - Phir aage bolo: *"WhatsApp kholo aur Ali ko salam likho"* ya *"Kya haal hai?"*

## APK Download Karne Ka Tareeqa (GitHub):
1. Is ZIP ko extract karo.
2. GitHub par ek New Repository bana kar saari files upload karo.
3. **Actions** tab mein ja kar **Kairo-AI-Agent-APK** download karo aur mobile mein install kar lo.
